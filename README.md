# 타자 연습 게임 (Typing Practice Game)

웹 기반 타자 연습 게임 | React + Vite

## 기능
- 60초 타이머 타자 연습
- 난이도 선택 (Easy / Normal / Hard)
- 최고 점수 저장 (localStorage)
- 광고 + Stripe 결제 기반 수익화 구조
- 프리미엄: 광고 제거, Hard 난이도, 상세 통계(WPM/CPM/정확도), 커스텀 단어 업로드

## 기술 스택
- React + TypeScript + Vite
- Tailwind CSS
- Stripe Payment Links
