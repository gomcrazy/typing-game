🎮 게임 방법

  1. 난이도를 선택하고 게임 시작 버튼을 누르세요.
  2. 화면에 표시되는 단어를 입력창에 정확히 입력하세요.
  3. Enter 또는 Space를 누르면 정답 여부를 확인합니다.
  4. 60초 동안 최대한 많은 단어를 맞추세요!
  5. 게임 종료 후 닉네임을 입력하면 순위보드에 기록됩니다.

⚡ 난이도 안내

쉬움

영어 3~4자, 한글 2~3자의 짧은 단어

예: cat, dog, 해, 달

보통

영어 5~7자, 한글 4~6자 단어

예: apple, cloud, 컴퓨터, 자동차

어려움 ⚡

영어 8~12자, 한글 6~9자 긴 단어

예: algorithm, 인공지능, 머신러닝

🏆 점수 시스템

  • 단어를 정확히 입력할 때마다 +1점
  • 틀린 단어는 점수가 오르지 않습니다
  • 최고 기록은 기기에 자동 저장됩니다
  • 상위 10개의 순위가 순위보드에 표시됩니다

📊 상세 통계

  • 정확도 — 전체 시도 대비 정답 비율
  • WPM — 분당 정답 단어 수
  • CPM — 분당 입력 타수
  • 커스텀 단어 — .txt 파일로 나만의 단어 목록 업로드

💡 팁

  • 입력창 테두리가 초록색이면 올바르게 입력 중입니다
  • 테두리가 빨간색이면 단어가 맞지 않습니다
  • 남은 시간이 5초 이하가 되면 타이머가 빨간색으로 깜빡입니다
  • 한글 단어도 포함되어 있으니 한/영 전환에 유의하세요

본 서비스는 외부 서버에 어떠한 개인정보도 전송하거나 저장하지 않습니다. 모든 데이터는 사용자 기기의 브라우저 로컬 스토리지(localStorage)에만 저장됩니다.

2. 정보의 이용 목적

  • 게임 최고 점수 및 순위보드를 기기에 유지하기 위함
  • 마케팅, 광고, 분석 등 다른 목적으로는 사용하지 않습니다

3. 정보 보관 기간

저장된 데이터는 사용자가 직접 삭제하거나 브라우저 데이터를 초기화하기 전까지 유지됩니다. 게임 내 '순위 초기화' 버튼으로 순위보드를 직접 삭제할 수 있습니다.

4. 제3자 제공

본 서비스는 수집된 정보를 어떠한 제3자에게도 제공, 판매, 공유하지 않습니다.

5. 쿠키 및 추적

본 서비스는 쿠키(Cookie)를 사용하지 않으며, 사용자 행동을 추적하는 분석 도구를 사용하지 않습니다.

6. 개인정보 삭제 방법

  • 게임 화면의 '순위 초기화' 버튼으로 순위보드 삭제
  • 브라우저 설정 → '사이트 데이터 지우기'로 모든 로컬 데이터 삭제

7. 문의
