📖 게임 설명

⌨️ 타자 연습 게임

  1. 홈 화면에서 타자 연습을 선택하세요.
  2. 난이도를 고른 뒤 게임 시작 버튼을 누르세요.
  3. 화면에 표시되는 단어를 정확히 입력하고 Enter 또는 Space를 누르세요.
  4. 60초 동안 최대한 많은 단어를 맞추세요!
  5. 게임 종료 후 닉네임을 입력하면 순위보드에 기록됩니다.

⚡ 타자 게임 난이도

쉬움

영어 3~4자, 한글 2~3자의 짧은 단어

예: cat, dog, 해, 달

보통

영어 5~7자, 한글 4~5자 단어

예: apple, cloud, 컴퓨터, 자동차

어려움 ⚡

영어 8자 이상, 한글 6자 이상 긴 단어

예: algorithm, 인공지능, 머신러닝

🏆 타자 게임 점수 시스템

  • 단어를 정확히 입력할 때마다 +1점
  • 게임 종료 시 WPM(분당 단어 수), CPM(분당 타수), 정확도를 확인할 수 있습니다
  • 최고 기록은 기기에 자동 저장됩니다
  • 상위 10개의 기록이 순위보드에 표시됩니다

🧠 기억력 카드 게임

  1. 홈 화면에서 기억력 카드 게임을 선택하세요.
  2. 난이도를 고른 뒤 게임 시작을 누르세요.
  3. 게임 시작 후 3초 동안 모든 카드의 위치를 보여줍니다 — 잘 기억하세요!
  4. 카드가 뒤집히면 같은 그림끼리 두 장을 맞춰 보세요.
  5. 모든 쌍을 맞추면 게임이 종료되고 걸린 시간이 기록됩니다.
  6. 닉네임을 입력하면 순위보드에 등록됩니다.

📱 스마트폰 사용 방법

  • 타자 게임: 단어 화면을 탭하면 키보드가 자동으로 올라옵니다
  • 타자 게임: 입력 후 완료(Return) 버튼을 누르면 정답 처리됩니다
  • 기억력 게임: 카드를 탭하여 뒤집으세요
  • 화면을 가로로 돌리면 더 넓은 화면에서 플레이할 수 있습니다

💡 단어 제안

  • 타자 게임에 추가하고 싶은 단어를 타자 연습 화면 하단에서 제안할 수 있습니다
  • 관리자가 검토 후 승인하면 전체 사용자에게 즉시 적용됩니다

💡 팁

  • 타자 게임: 입력창 테두리가 초록색이면 올바르게 입력 중, 빨간색이면 틀린 입력입니다
  • 타자 게임: 남은 시간이 5초 이하가 되면 타이머가 빨간색으로 깜빡입니다
  • 기억력 게임: 3초 프리뷰 동안 패턴이나 위치를 빠르게 스캔하세요
  • 언제든 상단의 🏠 홈으로 버튼을 누르면 게임 선택 화면으로 돌아갑니다

🎯 Type Speed Master란?

Type Speed Master는 타자 연습과 기억력 트레이닝을 한 곳에서 즐길 수 있는 웹 기반 미니 게임 플랫폼입니다. 별도의 설치 없이 브라우저만 있으면 누구나 바로 플레이할 수 있으며, 모바일과 PC 환경 모두에 최적화되어 있습니다.

타자 연습 게임은 60초 동안 제시되는 단어를 빠르고 정확하게 입력해 WPM·CPM·정확도를 측정합니다. 반복 연습을 통해 타자 속도와 정확도를 꾸준히 향상시킬 수 있습니다.

기억력 카드 게임은 3초 프리뷰 후 카드를 뒤집어 같은 그림끼리 맞추는 집중력·기억력 훈련 게임입니다. 짧은 시간 안에 두뇌를 활성화하는 데 효과적입니다.

두 게임 모두 게임별 독립 순위보드를 제공하여, 전국 플레이어들과 기록을 비교해볼 수 있습니다. 앞으로도 더 다양한 게임과 기능을 추가할 예정입니다.
